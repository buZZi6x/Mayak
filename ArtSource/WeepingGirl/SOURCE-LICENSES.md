# Weeping girl source assets

The replacement character uses an anatomical source mesh rather than the rejected procedural mask. No MakeHuman application/plugin is installed into Unity; only the selected authored mesh, shapes and one texture are exported.

## Human anatomy and rig weights — CC0

- MakeHuman Community, core `base.obj`, female-young target, default skeleton and weights.
- Source repository: https://github.com/makehumancommunity/makehuman
- Core-assets license: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md
- License statement: https://www.makehumancommunity.org/about/license.html
- Exact source headers and CC0 legal text are retained in `MakeHumanCC0/`.
- Adaptations: metric scale, quiet closed-mouth figure, exposed-skin extraction, relaxed authored poses, source rig weights aggregated for nine baked rise shapes. The nightdress geometry and its drape are authored for this project.

## Hair — CC BY 4.0, 04saken

**o4saken_long01**, original author **04saken**, distributed by the MakeHuman Community (asset index uploader: punkduck), licensed **Creative Commons Attribution 4.0 International** according to the asset's own `o4saken_long01.mhclo` header.

- Download page: https://www.makehumancommunity.org/assets/assetpacks/hair01.html
- Download archive: https://files2.makehumancommunity.org/asset_packs/hair01/hair01_cc0.zip
- License: https://creativecommons.org/licenses/by/4.0/
- Exact license text: `MakeHumanCC0/hair/o4saken_long01/LICENSE-CC-BY-4.0.txt`.
- Adaptations: fitted to the female source anatomy, lower strands moved over the loose nightdress, head/neck/chest deformation weights, source material adapted to a matte ghost with alpha clipping. The RGBA texture is copied unchanged.

The containing pack's webpage labels this item CC0, but its own source file declares CC BY 4.0. This project preserves the stricter explicit attribution rather than relabelling the source. Include the attribution above and the license URL with redistributed builds/assets, for example in `THIRD_PARTY_NOTICES.md` delivered beside the game.

The inspected but unused Cortu/culturalibre hair variants are not runtime dependencies. The entire download pack is not needed for reproduction once the selected o4saken source files are retained.
